#  FocusMap НГУ — Умная карта кампуса

**FocusMap НГУ** — браузерное расширение для Chrome, которое помогает студентам Новосибирского государственного университета находить свободные, тихие аудитории с розетками в реальном времени.

> **Проблема:** Студенты НГУ тратят время, обходя корпуса в поисках места для учебы.
> 
> **Решение:** Социальная карта кампуса, где сами студенты отмечают загруженность аудиторий.

---

## Возможности

### Интерактивная карта
- Отображение **всех коворгингов в НГУ** с поэтажными планами
- Цветные маркеры аудиторий:
  - 🟢 **Тихо** — можно спокойно работать
  - 🟡 **Шумно** — есть люди, но не критично
  - 🔴 **Занято** — пара или мероприятие
- Автоматическое определение корпуса и этажа по URL страницы

### ️ Социальное голосование
- Голосование за статус любой аудитории в 1 клик
- Мгновенное обновление маркеров у всех пользователей
- Автоматический пересчет статуса на основе большинства голосов

### Система репутации 
- Каждый пользователь имеет рейтинг от **0.00 до 5.00**
- **+0.02** к рейтингу за правильный голос (совпадение с большинством)
- **-0.10 / -0.25** за ошибку (чем серьезнее — тем больше штраф)
- Голоса пользователей с рейтингом ниже **3.00** не учитываются
- Вес голоса зависит от рейтинга (чем выше — тем больше влияния)

### Режим модератора
- Добавление новых рекреаций кликом по карте
- Перемещение маркеров двойным кликом
- Удаление неактуальных аудиторий

### Боковая панель
- Список всех коворгингов текущего этажа
- Быстрое голосование без клика по маркеру
- Отображение рейтинга и статистики пользователя

##  Установка Через GitHub 

1. Нажмите зеленую кнопку «Code» (в правом верхнем углу).
2. В выпадающем меню выберите «Download ZIP».
3. Дождитесь скачивания zip.
4. Откройте браузер и В адресной строке введите:
 ``chrome://extensions/
5. В правом верхнем углу страницы найдите переключатель «Режим разработчика» и включите его. Появятся три новые кнопки: «Загрузить распакованное расширение», «Упаковать расширение», «Обновить».
6. Нажмите кнопку «Загрузить распакованное расширение».
В открывшемся окне найдите папку, которую вы должны были распаковали после 2 пункта. Выделите всю папку и нажмите «Выбрать папку». В списке расширений появится «FocusMap НГУ» с иконкой.
